# Yushi's iPhone

2013년 4월 4일(목) 기준, 유우시의 휴대폰을 직접 조작해 보는 창작 웹사이트입니다.
등장인물과 설정은 모두 창작물의 세계관입니다.

## 실행 방법

- **내 컴퓨터에서:** `index.html`을 더블클릭하면 브라우저에서 열립니다. 서버는 필요 없습니다.
- **GitHub Pages:** 이 폴더의 파일을 저장소 맨 위에 그대로 올립니다. 그다음 Settings → Pages에서 `main` 브랜치의 `/ (root)`를 선택합니다.

## 조작

| 동작 | 결과 |
|---|---|
| 잠금 화면 손잡이를 오른쪽 끝까지 밀기 | 홈 화면 |
| (키보드) 손잡이 선택 후 → 또는 Enter | 홈 화면 |
| 홈 화면 아이콘 | 앱 열기 (모든 앱이 열림) |
| 앱 안에서 홈 버튼 | 홈 화면으로 |
| 기기 위쪽 오른편 잠자기 버튼 | 화면 끄기 / 다시 켜면 잠금 화면 |
| 화면이 꺼진 상태에서 홈 버튼 | 잠금 화면 켜기 |

볼륨 버튼, 무음 스위치, 잠금 화면 카메라 손잡이는 모양만 있습니다.

## 파일 구조

```
index.html        기기와 화면의 뼈대
css/device.css    기기 외형 (흰색 전면, 은색 테두리, 버튼)
css/ios6.css      화면 안쪽 (상태 표시줄, 잠금 화면, 홈 화면, 앱 화면)
js/config.js      날짜·시각·통신사·배터리·배경화면 설정  ← 주로 여기만 수정
js/icons.js       아이콘 그림 (SVG)
js/apps.js        홈 화면 앱 목록, 앱 연결 여부(ready)
js/main.js        동작 코드
```

## 자주 바꿀 것

- **시각:** `js/config.js` → `time: { hour: 9, minute: 53 }`. 시간은 24시간 기준으로 입력합니다.
- **시계 멈추기:** `clockRuns: false`
- **배경화면 이미지:** `assets/wallpaper-lock.jpg`(잠금), `assets/wallpaper-home.jpg`(홈). 바꾸려면 같은 이름으로 덮어쓰거나 `js/config.js`의 `wallpaper` 경로를 고칩니다.

## 아이콘 · 카메라 (4단계)

- 모든 아이콘을 2013년 입체 아이콘 느낌으로 새로 그렸습니다 (`js/icons.js`). 이 프로젝트만의 그림이며 실제 회사 아이콘을 베끼지 않았습니다.
- 비디오 앱을 없앴습니다.
- **카메라 앱** (`js/apps/camera.js`, `css/camera.css`)
  - 열면 조리개가 열리듯 나타나고, 보는 사람이 브라우저에서 카메라를 허용하면 실제 화면이 보입니다.
  - 셔터를 누르면 사진이 찍히고, 왼쪽 아래 작은 사진을 누르면 찍은 사진을 볼 수 있습니다.
  - 찍은 사진은 페이지를 연 동안만 남고 어디에도 저장·전송되지 않습니다.
  - 카메라를 쓸 수 없으면(허용 안 함, 카메라 없음) 안내 문구 없이 검은 뷰파인더(격자, 플래시·옵션·전환 모양)만 보입니다.
  - GitHub Pages(https)에서는 카메라가 작동합니다.

## 메시지 앱 (5단계)

- 독의 **메시지**: 메시지함(대화 목록) → 대화 화면 (`js/apps/sms.js`, `css/sms.css`)
- 데이터: `js/data/messages-data.js`
  - `type: "imessage"`면 파란 말풍선, `"sms"`면 초록 말풍선
  - `unread: true`면 목록에 파란 점, `readAt`을 적으면 마지막 보낸 메시지 아래 '읽음 오후 7:47'
- 입력칸을 누르면 화면 속 키보드가 올라오고, 전송한 메시지 아래에는 '전송됨'이 붙습니다. 왼쪽 카메라 버튼은 모양만 있습니다.
- 아이콘: 음성 메모는 보라색, 카메라는 흰 바탕에 검은 카메라로 바꿨습니다.

## Talk 수정 (6단계)

- 프로필(친구 목록·더보기·대화방 메뉴)은 눌린 표시만 되고 안으로 들어가지 않습니다. 유우시 프로필 사진: `assets/people/yushi.jpg`
- 아래 탭: 친구 · 채팅 · 더보기 (더보기 = 설정 화면: 내 프로필(사진·이름), 알림·친구 ON/OFF, 숨김·차단친구 관리, 글자 크기(대화방에 실제 적용), 공지사항, 버전 정보)
- 대화방 위쪽: 왼쪽 '채팅' 뒤로 버튼, 오른쪽 세 줄 메뉴 버튼
- 그룹채팅방: `chats`에 `name`(방 이름)과 `members`(참여자)를 적으면 됨. 목록 사진은 참여자 4명 얼굴, 대화방 메뉴에 '대화상대 N명'
- 날짜는 가로로 긴 막대로 표시, `{ system: "..." }`로 안내 문구 추가 가능, 메시지에 `unread: 1`을 적으면 말풍선 옆에 안 읽은 수 표시

## 이모티콘 키보드 (7단계)

- 키보드의 지구본 버튼: 한글 → 영어 → 이모티콘 → 한글 순서로 바뀝니다.
- 이모티콘 화면: 아래 막대에서 최근 사용 · 얼굴 · 자연 · 사물 · 장소 · 기호를 고르고, 옆으로 넘겨 더 볼 수 있습니다.
- 2010년 유니코드 6.0에 있던 이모지만 넣었습니다 (2013년 아이폰에 있던 범위).
- 그림은 보는 사람 기기의 이모지 글꼴로 보입니다. 아이폰·맥에서는 애플 이모지, 윈도우·안드로이드에서는 각 기기의 모양입니다.
- 지우기는 이모지 하나를 통째로 지웁니다.

## Talk Story 개편 (8단계)

- 위쪽 탭: 소식 · 내 스토리 · 친구 · **설정**
- 오른쪽 위 버튼으로 **스토리 쓰기** (글 + 사진 자리, 페이지를 연 동안만 남음)
- 소식: 이름 줄 + 흰 카드, 사이사이에 'OO님이 프로필 사진을 변경했습니다.' 같은 활동 알림 (`activities`)
- 내 스토리: 큰 사진 + 작은 프로필 사진 + 이름 · 스토리 수 · 친구 수 · 'OO월 OO일생'(`birthday: "04-05"`) + 스토리 격자
- 친구: 이름·초성 검색, 아래 '친구 / 친구추천(`suggestions`) / 받은신청(`requests`)'
- 설정: 알림 ON/OFF 스위치, 스토리 공개 범위, 공지사항, 버전 정보

## Safari 검색·방문 기록 (10단계)

- 주소칸 옆 검색칸을 누르면 '최근 검색'(`webSearches`)이 나오고, 항목을 눌러도 눌린 표시만 되고 다른 화면으로 넘어가지 않습니다.
- 북마크 화면 맨 위 '방문 기록' 폴더(`webHistory`): 오늘 / 어제 / '4월 2일 화요일'처럼 날짜별로 묶여 보입니다.
- 두 목록 모두 '지우기'로 비울 수 있고, 새로고침하면 데이터 파일 상태로 돌아갑니다.

## 홈 화면 두 번째 페이지: 시간표

- 홈 화면을 왼쪽으로 넘기면 시간표가 나오고, 홈 버튼을 누르면 첫 페이지로 돌아옵니다.
- 데이터: `js/data/timetable-data.js` (과목·강의실·요일·시작/끝 시각·색)
- 화면 코드: `js/timetable.js`, 스타일: `css/timetable.css`

## 저절로 쳐지는 글 (draft)

- `js/data/wink-data.js`의 대화방에 `draft: "글"`을 적으면, 독자가 그 방 입력칸을 누를 때 화면 속 키보드가 한 글자씩 눌리며 글이 쳐집니다.
- 전송은 독자가 직접 누르고, 한 번 쳐지면 다시 쳐지지 않습니다 (새로고침하면 처음부터).
- 지금은 시오니~ 방에 "그래도 좀만 참으면 된다"가 들어 있습니다.
- 대화방에 `afterDraft: { delay: 15, gap: 7, messages: ["…", "…"] }`를 적으면, 독자가 준비된 글을 보낸 뒤 delay초 뒤에 첫 메시지, 그다음부터 gap초 간격으로 상대가 보냅니다.
  - 독자가 그 방을 보고 있으면 바로 말풍선이 생깁니다.
  - 다른 화면(채팅 목록, 다른 앱, 홈 화면)에 있으면 위쪽에 배너 알림이 내려오고, 누르면 그 대화방이 열립니다. 홈 화면 Talk 아이콘과 채팅 탭에 안 읽은 수가 붙습니다.

## 카메라 롤 동영상

- `js/data/apps-data.js`의 `photos`에 `{ video: "assets/videos/파일.mp4", poster: "assets/videos/파일.jpg", duration: 초 }`를 넣으면 비디오로 보입니다 (작은 칸에 비디오 표시·길이, 누르면 재생).
- 동영상은 H.264 mp4로 넣어야 모든 브라우저에서 재생됩니다.
- `afterDraft` 안에 `next: { draft: "다음 글", readNow: true, delay, gap, messages }`를 넣으면 대화가 이어집니다. 상대 답장이 다 온 뒤 입력칸을 누르면 다음 글이 쳐지고, `readNow`면 보내자마자 '1'이 사라집니다.
- 지금 시오니~ 방 흐름: "보고 싶다잉" → (15초) "나도 보고 싶어잉" → (7초) "그래서 우리 우시 보러 가는 중" → "에 나니 뭐야???" (보내면 바로 읽음) → (6초) "ㅎㅎㅎ" → (4초) "오늘 3시에 끝나는 거 맞지?" → (4초) "이따 데리러 갈게~~ 파이팅"
- 톡이 올 때 알림음(`assets/sounds/talk.mp3`)이 납니다. 독자가 그 대화방을 보고 있을 때는 나지 않고, 다른 화면에 있을 때만 납니다. Talk 더보기에서 새 메시지 알림이나 알림음을 끄면 소리가 나지 않습니다.

## 시오니~ 전화 장면

- 독자가 Talk 시오니~ 방에서 "그래서 우리 우시 보러 가는 중"을 **본 뒤에** 시오니~에게 전화를 걸면, 4초 뒤 받고 대사가 자막으로 차례로 나온 뒤 전화가 끊깁니다.
- 그 전에 걸면 예전처럼 '호출 중...'에서 멈춥니다. 한 번 통화한 뒤에는 다시 '호출 중...'입니다 (새로고침하면 처음부터).
- 대사·간격: `js/data/phone-data.js`의 `callScripts.sion` / 열리는 조건: `js/data/wink-data.js` 시오니~ 방의 `unlockOnSeen`
